## Architecture

Extend existing product policy with verified content constraints and account health. Main computes preflight and rejects job creation on blockers. Existing final-submit, durable intent, reconciliation and ordinary/batch switches remain authority. Developer mode defaults off and cannot bypass Main gates.

Extend existing AI provider profile persistence and SafeStorage credential references. A text client handles verified OpenAI-compatible transports and Ollama native chat/tags, with provider-specific headers. Renderer sees metadata and accepts a write-only secret field. List/test are explicit operations; generation never retries transport uncertainty automatically. No image, speech, embeddings or agent pipeline.

Content Studio uses existing brands, articles and variants plus versioned enterprise context/templates/generation metadata. Generation output is editable local draft only. Selected company/source/template/model/platform are captured. Deterministic checks use the shared content policy, approved/forbidden claims and other known brands/contacts. A maximum one title-format repair uses the same model/provider, preserving body and facts; unresolved output needs user action. Same-company recent duplicate checks are warnings (latest 100 local articles), because the supplied specification ends at “同企业最近”.

Provider contract sources checked 2026-10-01: Xiaomi official first-api-call (api.xiaomimimo.com/v1, api-key, chat/completions, max_completion_tokens); OpenAI official chat completion/models references; DeepSeek official first-call; Ollama official tags/chat. Configurable models; no live cloud generation required without credentials. Local HTTP fixtures test contracts and errors.
