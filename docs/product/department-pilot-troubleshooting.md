# 遇到问题怎么办

| 看到的情况 | 下一步 |
| --- | --- |
| Windows/公司策略阻止安装或 Start-Pilot | 保存完整提示、软件摘要和来源，交 Owner/IT 核对；不调低安全策略 |
| 入口显示 SOFTWARE 不匹配或资源缺失 | 停止打开数据，重新核对本轮唯一安装包、安装目录和 SOFTWARE.json；保留现场 |
| 首次启动没有企业/账号/AI Key | 创建并选择企业工作区，练习合成导入；真实登录/授权等待 Owner |
| 企业资料无法读取/创建失败 | 保存提示，使用“重新读取资料”；表单保留输入。不要重置、删库或改数据库状态 |
| 导入逐行错误 | 查看标题/正文、企业工作区和字段映射。修正原表后重新预览；模板的较长标题进入 Draft 后仍需按平台缩短 |
| 草稿显示保存失败或冲突 | 保持当前编辑页面，导出/保留文本；检查差异并明确选择恢复。未看到“已保存”就不要关机 |
| 已批准后又改文章 | 修改会撤销批准，重新人工审核；不以旧批准继续发布 |
| 浏览器缺失/登录失效/验证码 | 联系 IT 检查系统 Edge/Chrome；由账号本人完成平台正常登录与验证，恢复后再核对身份 |
| 账号未确认或素材属于另一企业 | 返回账号归属和工作区核对；不通过改昵称或选另一个企业绕过 |
| AI 预算/余额未知、取消或结果 Unknown | 核对原请求和预算；取消不保证供应商退款，Unknown 不自动重放。今晚未发真实 AI 请求 |
| 发布结果 Unknown/NeedsReconciliation | 停止该原任务的写操作，保留 Job/Intent/回执，按原操作只读核对；不重新发一条 |
| 完整备份 Incomplete 或校验失败 | 保留原数据与失败快照，导出脱敏诊断，联系 Owner。只有 Complete 且校验通过后才能用于恢复验收 |

导出问题资料：“高级功能 → 导出脱敏 Diagnostic Bundle”。私有业务、账号、Cookie、Token、Key、完整快照、Local State、浏览器目录和原生产截图留在受控私有位置；公开反馈使用脱敏诊断和合成截图。

历史缺图涉及 5 项 Job 选择引用及 4 条 PublishRecord 的选择/回执关系，本轮没有处理。原生产升级和“退休记录”均等待 Owner 的单独决策与备份重验。
