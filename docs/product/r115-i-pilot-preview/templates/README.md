# 普通 UI 导入模板

入口固定为 **内容运营 → 批量导入 → 选择 CSV / XLSX**。另一个“文章库 → Excel 导入”使用不同可选字段名，勿混用本说明的映射。首次练习企业名为 **合成试用企业**。

| 本模板列 | 必填 | 处理 |
| --- | --- | --- |
| 标题、正文 | 是 | 标题最多 200 字符，正文最多 200000 字符；平台还有自己的长度限制 |
| 企业 | 否 | 空值归当前工作区；填写时须与当前企业一致，冲突行不能导入 |
| 摘要、业务、城市、关键词、标签 | 否 | 可空；中文和正文单元格中的换行保留 |
| 目标平台、内容类型、推广强度 | 否 | 必须使用产品现有合法值；模板留空，发布时再明确选择，不触发发布 |
| 来源说明 | 否 | 本模板写入来源日期文本；本导入入口没有单独日期列，不虚构日期字段 |
| 模板版本 | 否 | 留空按 1.0；示例明确为 1.0 |

文章导入模板.xlsx 有两条明显合成资料，包含中文、换行、来源日期文本、较长标题及空可选列。合成示例.csv 是同一首条资料，可检查同企业重复保护。校验问题示例.csv 演示缺标题、企业冲突、超长标题和缺正文，预览应拦截。

公式静态检查.xlsx 仅用于验收，含一个 1+1 公式及文件内缓存数值 2。产品读取缓存值文本，不计算公式、不执行指令、不调用 AI 或创建 Job。业务表格建议提交静态文本；不要在 CSV 中放可被表格软件执行的公式、宏或外部链接。

每个文件最大 8MB、一次最多 1000 行；此入口读取第一张工作表。先检查映射和逐行错误，修正后重新预览，再 Import as Draft。安装版普通 UI 会实际导入此模板，并验证三条 Draft、重复保护、企业冲突、公式缓存和无发布任务。
