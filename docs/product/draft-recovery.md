# 草稿保存与恢复

文章编辑和 AI Studio 编辑使用本机工作副本。输入期间显示「保存中」，只有 Main 持久化确认后显示「已保存」。普通输入在短延迟后保存，中文组合输入完成前不会提交半段文本。

「保留工作副本并关闭」保留未提交编辑；「提交修改并重新审核」将工作副本提交为当前内容。保存失败时保留页面和文本，按错误提示重试。导航、企业切换和正常退出会先刷新编辑；输入尚未完成或保存失败时应留在编辑页处理。

重启后，打开同一企业的同一草稿，可以「查看差异」「恢复上次编辑」或「保留当前版本」。原文出现新版本时不会自动覆盖，必须明确选择。原文已经删除时，恢复文本仍可在差异区复制，不能覆盖其他文章。

工作副本与企业、文档和基础版本绑定。含未提交编辑的内容不能沿用旧批准进行正式发布；提交改变后的正文需要重新人工审核。历史 Job、SubmissionIntent 和 PublishRecord 不被草稿编辑或恢复改写。

AI 请求结果不确定时不会自动重发。若已有确定收到的原始草稿，可人工修正并保存；在运营队列「重新对账」只核对保存结果。继续剩余预算生成必须另点明确按钮，原 Unknown 请求记录仍保留。
