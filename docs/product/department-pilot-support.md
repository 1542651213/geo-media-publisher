# 当前支持范围

部门试用先选择一个企业、一位负责人、一台主要发布电脑。下表是产品当前开放范围，能否真实发布仍取决于 Owner 授权、有效身份、人工审核和逐项发布条件。

| 平台/能力 | 当前范围 | 首日需要 |
| --- | --- | --- |
| 抖音 | 单账号、单张图、标题最多 20 个 UTF-16 单位、公开、立即发布、无音乐；准备后再确认最终提交 | 系统 Edge/Chrome、正常 Creator 登录、明确所属企业及正确素材 |
| 今日头条 | 单账号文章、纯文本正文、单张人工选择的同企业封面；准备后确认一次 | 系统 Edge/Chrome、正常 Creator 登录、确认账号身份和当前文章 |
| 康一正式官网 | 现有 OfficialAPI，ARTICLE/CASE；图片/内容按官网字段检查，准备后单独确认 | 正式站点和 production 环境由 Owner 核实，通过 Main 安全导入授权；旧退役凭据不复用 |
| 其它白名单平台 | 继续关闭或等待既有产品验收门禁，不作为首批试用渠道 | 首批路径跑通后另行验收 |
| 文章、素材、事实 | 新库普通 UI 导入 Draft、素材入库、人工审阅、自动保存、同事资料包 | 核对企业和真实来源；事实重新核实/批准 |
| AI | 保留现有服务商与预算/取消/Unknown 保护；无 Key 不发起生成 | 本轮没有真实云生成；如明天要测，单独批准 Key 使用和小额预算 |
| 发布历史/Unknown | 按原任务与回执核对；看板模拟截图只演示提醒 | 不用重新创建任务、重试提交或手动改成 Success 处理未知结果 |

ALL_BATCH = OFF。定时自动发布、批量发布、新平台、新服务商均不属于本轮。康一候选账号是私有证据，不是自动归属确认；新库不需要第一天处理完 28 个历史账号。

一个发布账号由一名负责人、一台主要电脑操作是运营约定，软件没有声称实现跨机器重复发布锁。禁止多台电脑共同写一个活动 SQLite 文件；同事自行登录/授权，不复制凭据文件来声称免登录。
