# 部门试用：开始使用

本次交付为 **R1.15-I DEPARTMENT PILOT CANDIDATE / 应用 1.1.9**，保留 H.2 紫色界面。今晚准备与验收均使用合成资料；真实账号与业务发布由 Owner 明天单独验收。main 保持 H Candidate。

1. 从本轮 Candidate prerelease 下载唯一部门 ZIP，解压到本机。按 SHA256SUMS 校验安装包；软件未签名，如 Windows 或公司策略阻止，保留提示交由 Owner/IT 核对来源，不降低安全策略。
2. 运行 ZIP 中的安装程序，选一个新的程序目录。既有软件保留。安装器不自动启动，也不创建会误开旧数据的桌面/开始菜单快捷方式。
3. 双击 ZIP 中的 **Start-Pilot.cmd**，首次选择刚安装目录里的 **Geo Media Publisher.exe**。启动器校验 I 包身份，并使用当前 Windows 用户的独立部门试用数据目录；以后继续使用同一入口。
4. 在“设置 → 关于此版本”确认 **R1.15-I / 1.1.9 / 源码标识**，与 SOFTWARE.json 一致。启动窗口会说明本机试用数据路径。关闭后再打开，沿用同一试用目录。
5. 空库点击右上角“创建企业资料”，填写经核对的企业名称/简称。练习时填写 **合成试用企业 / 合成试用**；明天 Owner 选定真实企业后再填写真实资料。
6. 在“内容运营 → 批量导入”选择合成文章模板，先看字段映射和逐行错误，再点 **Import as Draft**。导入不会创建发布任务。错误练习文件只供预览，不必导入。
7. 在“文章库 → 修改”编辑正文，等待“已保存”；退出重开后按“恢复上次编辑”检查，再“提交修改并重新审核”。批准文章或事实需逐项人工核对；导入不继承批准状态。
8. 在“图片库 → 上传图片”选择本机有使用权的图片，选择正确企业并保存。今晚仅使用合成样本。
9. “账号中心”无账号、“AI 服务商”无 Key、“发布中心”准备按钮不可用，都是新库的正常初始状态。真实登录、安全导入凭据、企业归属及首次发布按[首日清单](day-one-acceptance.md)由 Owner 单独批准。
10. 收工在“高级功能 → 数据备份”创建完整快照并正常退出，重开后校验快照；失败保持 Incomplete，不把复制成功当作恢复通过。
