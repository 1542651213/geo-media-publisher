# 员工最短操作路径

1. 在侧栏及「设置 → 关于此版本」确认应用版本、R1.15-G、构建时间和 source commit，选择当前企业工作区。
2. 到「内容运营 → Owner 处理」查看未确认账号。员工不替 Owner 猜企业归属，必要时由 Owner 完成确认和正常登录。
3. 在「批量导入」选择 CSV/XLSX，核对字段映射和逐行错误。修正文件或排除错误行，导入仅创建本地 Draft。
4. 在文章库编辑，等到「已保存」。返回、切企业或退出前保留工作副本；重启发现恢复内容时先查看差异。
5. 配置服务商后，在内容生产或草稿生成队列预览 AI 工作量，展开检查将发送的企业资料、允许事实、源稿和模板，再确认预算。界面显示基础请求、标题修复、有限重试和已发出数量；所有企业共享并发 1。
6. 不确定请求不自动重发；已发出的请求不退还预算。取消会停止后续请求，但已发送请求的结果仍需人工核对。缺 Key 时由 Owner 配置指定服务商，不借用其他服务商凭据。
7. 核对各平台草稿和重复提示，修正红项、保存 Draft、手选同企业素材，人工审核当前内容。修改后重新审核。
8. 正式操作继续走原来的发布中心与持久化 Job 链路。本轮演练止于本地预检；真实上传、远端草稿和最终提交需另行明确授权。
9. 正常退出前可创建完整快照，重新启动校验，并在新的隔离目录演练恢复。给同事只导出业务资料包，不发送私有备份。

当前普通发布开关：抖音、康一官网、头条保持 ON；其他门禁沿用 C/D/E/F，全部 batch OFF。开关为 ON 不代表每个账号已登录或已经完成真实发布验收。

版本与实测证据见 [G 验收说明](../releases/R1.15-G-READY.md)。
