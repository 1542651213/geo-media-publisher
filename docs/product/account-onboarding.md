# 账号整理与 Owner 确认

在「内容运营 → Owner 处理」查看历史账号。建议只来自已保存的发布任务、文章和企业关联；账号昵称不用于推断企业。唯一建议、冲突和无证据都需要 Owner 逐项核对。

1. 先把页面顶部的企业工作区切到真实所属企业，在账号行选择该企业，再点击「确认该账号企业归属」。跨企业变更需要页面上的明确确认；Main 会重新核对当前工作区、账号与绑定版本。
2. 正在运行或含不确定最终结果的历史任务可能阻止变更。先人工核对原任务，保留现场，不创建替代发布。
3. 确认后进入账号中心，在平台正常页面登录或更新指定凭据，再重新检查身份。企业确认不代表登录成功。
4. 遇验证码或安全验证，按平台正常流程完成。网络不可达保留为连接异常；手动停用不会被后台恢复自动启用。

Owner 页面展示的建议不会修改历史任务、发布记录或原账号归属。企业切换或重新确认会使旧的异步身份响应失效。本轮历史账号预览只在关闭后的私有副本完成；原生产库没有执行任何归属确认。

详情及已验证范围见 [G 验收说明](../releases/R1.15-G-READY.md)。
