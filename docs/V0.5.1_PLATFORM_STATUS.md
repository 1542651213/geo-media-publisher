## 代码边界

- 7 个新增平台已注册到运行时 `AdapterRegistry`：微博、百家号、知乎、搜狐号、视频号、小红书、企鹅号。
- `ManualOnly` Adapter 只允许本地 validation 和不触网 Dry Run；正式调用返回 `USER_ACTION_REQUIRED`，不会生成假的 external ID 或 URL。
- 微博只有在注入已审阅的 CLI contract 后才会执行 CLI；缺少 contract 时返回 `API_REVIEW_REQUIRED`。
- 快手即使测试注入合同，manifest 仍为 `Blocked`，不据此宣称真实平台支持。
- 没有新增 `packages/domain`、`packages/publisher` 或 `packages/db` 的修改；现有 Queue、PublishRecord、Reconciliation、Dry Run 和 Manual Confirmation 保持不变。
