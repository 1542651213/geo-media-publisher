# V0.3.1 人工验收

1. 在“系统设置 → AI 设置 → DeepSeek”填写 API Key，点击“保存密钥”，再点击“测试连接”。API Key 不需要写入 `.env`、源码或 Windows 环境变量。
2. 选择 `deepseek-v4-flash` 和经济模式，创建 10 篇 Mock/DeepSeek 文章批量任务，确认任务项在崩溃恢复后不会漏项或重复创建。
3. 在发布队列先执行 Dry Run，确认状态变为 `AwaitingConfirmation`；点击“确认正式发布”后才会调用正式 Publish API。
4. 对 `NeedsReconciliation` 任务先查询平台状态；只有确认平台未收到提交后，才点击“确认未提交后重试”。
