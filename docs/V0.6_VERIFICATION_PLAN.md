## 平台升级门槛

- `CodeComplete`：只代表代码边界和本地测试完成。
- `DryRunPassed`：必须有账号授权后的 Dry Run 记录，且 Dry Run 未触发真实发布。
- `PublishPassed`：必须有一次低量真实发布、External ID、可访问 External URL 和最终状态回查。
- `Stable`：必须在真实环境重复发布/回查，并有错误恢复和账号所有者验收证据。
- 任何验证码、安全验证、人机验证、短信确认或平台审核都暂停任务并交由用户完成；系统不绕过。

## V0.6.1 平台账号配置中心

账号中心是 V0.6 真实验收的配置入口，不是新的平台能力。它按已注册 Adapter 的 credential schema 展示账号配置：

| 平台 | 配置字段 |
|---|---|
| 微信公众号 | AppID、AppSecret |
| Facebook Pages | Meta App ID、OAuth 状态、Page ID；Page token 只由主进程安全保存 |
| 抖音 | Client Key、Client Secret、OAuth 状态 |
| YouTube | OAuth 状态及 Adapter 声明的 OAuth 凭据字段 |

账号卡片还必须展示平台名称、Adapter 状态、账号状态、Credential 状态、授权状态、最后验证时间、最后 Dry Run 时间和最后发布时间。最后 Dry Run 时间只从成功的真实 `PublishRecord` 派生，不能把本地 validation 当成真实通过证据。

“测试连接”只调用账号连接检查并记录脱敏验证日志；它不能改变平台生命周期，也不能把 `WaitingForUser` 升级为 `DryRunPassed`。只有真实 Dry Run 和真实发布证据可以触发生命周期升级。缺少真实账号、Meta App、Page 权限、AppID/AppSecret、OAuth 或其他平台必需条件时，保持 `WaitingForUser`。

Secret 继续通过 Electron 主进程 `safeStorage` 保存。任何日志、诊断导出、Renderer 状态或文档都不得输出 Token、Secret、Cookie 或完整 Authorization；日志只允许记录平台/账号标识、状态、时间和错误类型。

## 证据要求

每次验收至少保留：脱敏账号标识、授权完成时间、Credential 已配置/未配置、Job ID、Dry Run 或真实发布时间、PublishRecord ID、External ID、External URL、状态回查时间与结果、失败错误码/原因。禁止记录 AppSecret、Client Secret、Access Token、Cookie 或完整 Authorization Header。
