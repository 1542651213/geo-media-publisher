# V0.3 验收记录

## 工程审计

- 基线 migration 可从空数据库执行；V0.3 新增 `0002_v03_productization.sql`，没有重建或删除已有业务表。
- JSON 读取增加数组/字符串记录的形状过滤；文章、任务、发布记录和平台 Profile 通过仓储转换为领域模型。
- 发布调度使用 `listDueJobs(... LIMIT ...)`，不会把全部 Job 一次加载到调度器；账号、平台和全局并发有界。
- SQLite 备份使用 `better-sqlite3` online backup API，恢复前执行完整性校验。

## V0.3 新增能力

- AI：Provider Profile、默认/备用配置、有限并发（1–20）、任务进度、取消、启动恢复、Quality Gate、禁止编造项后置警告、相似度警告。
- Queue：`Publishing` 状态、单任务异常隔离、登录失效转 `NeedsUserAction` 并暂停账号、登录定期检查、平台连续失败暂停通知。
- WeChat：access token、封面素材、草稿、正式提交和 `freepublish/get` 状态回查；当前仍需要真实公众号凭据和人工验证。
- 运维：文章分页和发布历史、运行日志搜索、脱敏 ZIP、SQLite 备份/校验/恢复。
- Windows：electron-builder NSIS x64 安装包配置。
