## Browser 边界

本轮没有任何外部平台被标记为“官方允许 Browser 自动化”。`BrowserSessionManager` 只保留为受控基础设施；没有经过官方许可和已验证 selector 的平台不会启用 Browser Adapter。登录验证码、安全验证、人机验证必须暂停并交由用户在平台正常页面完成。
