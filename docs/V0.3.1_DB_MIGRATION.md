# V0.3.1 database migration

V0.3.1 adds migration `0003_v031_reliability.sql`. It is applied by the existing startup migration runner and is safe to run more than once.

The migration adds:

- `accounts.publish_mode` for inherit/manual/auto account policy.
- `publish_jobs.submission_intent_id` and `external_id` for crash-safe submission recovery.
- `submission_intents` for durable pre-submit, submitted, unknown, and not-submitted states.
- `ai_batches` and `ai_batch_items` for resumable batch generation without an in-memory cursor.
- `ai_tasks.batch_id` to connect the UI task to its durable batch.

Before restoring a database, the app validates SQLite integrity and creates a `.pre-restore-<timestamp>.db` safety copy. A restore is only accepted after the user confirms it in the UI.
