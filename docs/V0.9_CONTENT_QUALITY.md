# V0.9 AI Content Quality Gate

## 目标

V0.9 在 AI Content Studio、文章库与发布队列之间增加可审计的内容质量门禁。内容可以继续生成和编辑，但只有当前内容哈希对应的 `Approved` 版本可以创建发布队列任务。

## 九项检查

1. 品牌事实一致性：检查品牌名称、企业资料边界和品牌明确禁止的表述。
2. 禁止编造资质：发现认证、资质、证书、专利或权威背书而品牌资料没有依据时拒绝。
3. 禁止虚假承诺：发现保证结果、零风险、百分之百等结果承诺时拒绝。
4. 禁止绝对化营销词：发现全国第一、顶级、唯一、最好等绝对化用语时拒绝。
5. 城市关键词覆盖：城市与主关键词必须在标题或正文中自然出现。
6. 城市一致性：目标为木渎时拦截明显冲突城市；江苏、苏州、木渎的上下级服务范围按保守规则处理。
7. 平台长度要求：使用独立 `PlatformContentRules` 的标题、正文、摘要、标签和图片限制；没有确认官方规则时使用 `unverified` 保守 fallback。
8. SEO 质量：检查标题、摘要、SEO 关键词对主关键词的覆盖和正文信息量。
9. 内容重复度：与同品牌其他主题比较中文 n-gram 文本相似度，超过阈值时进入人工复核。

## PlatformContentRules

规则字段包括 `titleMinLength`、`titleMaxLength`、`bodyMinLength`、`bodyMaxLength`、`summaryMaxLength`、`maxTags`、`maxImages`、`supportsLinks`、`supportsMarkdown`、`supportsHtml`、`contentType`、`source` 和 `lastVerifiedAt`。规则从数据库读取，不在 React 页面硬编码。当前微信公众号、知乎、今日头条、新浪微博、抖音脚本、B站脚本均有配置，但因本轮未完成官方规则复核，统一标记 `unverified`，source 和 lastVerifiedAt 保持空值。

规则引擎默认使用 `quality-rule-engine / v0.9-deterministic`，结果不会替代人工批准。采用确定性规则是为了让每次审核可以复现、解释和审计。

## 状态流转

```text
Draft -> AI_Checked -> Approved
   |          |
   |          +----> Needs_Review -> Approved / Rejected
   +----------------> Rejected

人工编辑 -> Draft -> 自动复检
```

- `Draft`：新内容或内容哈希已变化，尚未有当前审核结果。
- `AI_Checked`：九项检查没有发现问题，等待人工批准。
- `Needs_Review`：存在警告，需要人工判断后再批准或拒绝。
- `Approved`：人工批准且内容哈希未变化，可以进入发布队列。
- `Rejected`：存在硬性问题，必须修改并重新检查；不能直接批准。

## 持久化

- `content_quality_states`：每个文章或平台 Variant 的当前状态、当前内容哈希、版本号和最后审核记录。
- `content_quality_reviews`：不可覆盖的审核历史，包含触发来源、检查结果、问题证据、分数、快照、Provider/Model 和时间。
- `content_quality_audits`：记录 system/human 操作的 operator type、previous status、new status、reason、timestamp 和 content hash；人工编辑、批准、驳回均留痕。
- `content_studio_versions` 增加 `quality_status` 与 `quality_review_id`，方便从生成历史直接查看当前审核状态。

## 运行时接入

- AI 批量生成和 Content Studio 平台版本生成完成后自动检查。
- 文章编辑、平台 Variant 编辑和 Content Studio 版本编辑后进入 `Draft` 并自动复检。
- AI Quality Gate 页面提供重新检查、批准、拒绝、编辑并复检、风险证据详情和审核历史；平台规则独立页面读取 `PlatformContentRules`。
- 发布计划创建 Job 前检查计划将使用的文章或平台 Variant；视频任务创建前检查关联文章。
- 没有修改平台列表、Adapter 实现、`packages/publisher`、Job Queue 或 Adapter Registry。
